Die Chip-Liste darunter bleibt immer die kanonische, vollständige Darstellung. Logik: assets/js/skill-graph.js (+ DOM-freie Engine skill-graph-sim.js), Präsentation als modales Sheet: assets/js/skill-graph-sheet.js. Daten: dasselbe JSON-Tag [data-skill-graph-data] wie die Chip-Hervorhebung. Ein Knopf öffnet das Sheet direkt. Ohne Sheet-Modul klappt das Panel inline auf (Progressive Enhancement), dann direkt unter dem Öffner. Öffner: zugänglicher Name = sichtbarer Text (Symbol aria-hidden), die Zeile daneben hängt als Beschreibung an (aria-describedby). Kopfleiste: zugängliche Namen beginnen mit dem sichtbaren Text (WCAG 2.5.3, STYLEGUIDE 7.7 „Reset“). Canvas tabindex="-1": nicht in der Tab-Reihenfolge, aber ein Klick hält den Fokus im Dialog (sonst fiele er auf , Tasten +/−/0 wirkungslos). {% endcomment %}
